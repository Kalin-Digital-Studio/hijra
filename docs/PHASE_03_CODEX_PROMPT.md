# Brief implementasi Phase 03 · Shalat Wajib Tracker

Gunakan baseline Hijra Expo SDK 58 dan data lokal dari Phase 01–02. Tambahkan migrasi non-destruktif, lima slot harian dari data master aktual, status manual, dua atribut tiga nilai, catatan privat, simpan otomatis, ringkasan harian/mingguan, dan riwayat serta konsistensi pekanan. Dashboard dan tab Ibadah membuka tracker harian. Gunakan awal pekan pilihan pengguna dan tanggal kalender lokal. Tanggal mendatang tidak dapat dicatat.

Pertahankan profil, preferensi, tema, lokalisasi Indonesia/English, dan fitur sebelumnya. Gunakan repository SQLite, aturan domain bersama, antrean simpan, serta status simpan yang jujur. Ikuti kebijakan lisensi dengan dependensi yang sudah tersedia. Tracker lain, jadwal, notifikasi, GPS, target, dan laporan penuh berada di luar lingkup.

Lakukan regresi otomatis dan pengujian pengembangan Android/iOS. Phase 03 ditutup setelah pemeriksaan pengembangan lulus dan masalah kritis diatasi. UAT formal tetap dijadwalkan pada Phase 12.

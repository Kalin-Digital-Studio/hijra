# Ringkasan proyek

**Hijrah** · Every day, a better journey.

Hijrah Apps adalah aplikasi Islamic Lifestyle untuk aktivitas ibadah pribadi. Phase 01 menyediakan fondasi offline-first untuk Android dan iOS. Dasbor membuka katalog Shalat Wajib, Shalat Sunnah, Al-Qur’an, dan Dzikir. Lima tab dapat dinavigasikan, dengan Ibadah, Target, dan Laporan menyediakan status fitur untuk fase mendatang.

Identitas aplikasi menggunakan slug `hijrah-apps`, skema `hijrah`, dan identifier Android serta iOS `app.hijrah.mobile`. Identifier ini dipilih untuk pengembangan Phase 01 dan perlu dikonfirmasi sebelum pendaftaran toko aplikasi.

Lihat [status implementasi](DEVELOPMENT_PROGRESS.md) dan [panduan UAT](UAT_CHECKLIST.md).

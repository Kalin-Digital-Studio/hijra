# Ringkasan proyek

**Hijra** · Every day, a better journey. · Kalin Digital Studio

Hijra adalah aplikasi Islamic Lifestyle untuk aktivitas ibadah pribadi. Phase 01 menyediakan fondasi offline-first untuk Android dan iOS. Dasbor membuka katalog Shalat Wajib, Shalat Sunnah, Al-Qur’an, dan Dzikir. Lima tab dapat dinavigasikan, dengan Ibadah, Target, dan Laporan menyediakan status fitur untuk fase mendatang. Phase 02 menambahkan pengenalan aplikasi, satu profil lokal, personalisasi, dan pengaturan awal pekan.

Identitas aplikasi menggunakan slug `hijrah-apps`, skema `hijrah`, dan identifier Android serta iOS `app.hijrah.mobile`. Identifier ini dipilih untuk pengembangan Phase 01 dan perlu dikonfirmasi sebelum pendaftaran toko aplikasi.

Lihat [status implementasi](DEVELOPMENT_PROGRESS.md) dan [panduan UAT](UAT_CHECKLIST.md).

Phase 03 menambahkan pencatatan Shalat Wajib, riwayat mingguan, dan ringkasan aktual di Beranda. Lima aktivitas yang ada pada data master dapat dicatat per tanggal kalender lokal.

Phase 04 menambahkan pencatatan beberapa sesi Shalat Sunnah per aktivitas dan tanggal, katalog yang dapat dipersonalisasi, serta ringkasan di Beranda dan riwayat pekanan.
